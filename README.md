# retail-data-warehouse

&gt; 基于 12 张业务表的多维度零售数据分析，通过 SQL 构建 RFM 客户价值模型，识别高价值客户、分析城市退货率、挖掘品类销售规律，为精细化运营提供数据支持。

---

## 📌 项目背景

某零售企业拥有多城市门店、多品类商品、多供应商的复杂业务体系，积累了大量订单、客户、退货、支付等数据。业务方面临以下核心问题：

- **客户分层模糊**：不知道谁是高价值客户，谁即将流失，营销资源投放缺乏针对性
- **城市运营差异大**：不同城市的退货率、复购率差异显著，但缺乏量化依据
- **品类管理粗放**：不清楚哪些品类退货率高、哪些品类受高复购客户青睐
- **高复购客户行为不清**：不了解忠诚客户的购买偏好（价格带、供应商偏好等）

## 🎯 分析目标

1. **构建 RFM 客户价值模型**，将客户划分为 5 个层级，支撑差异化运营策略
2. **识别高复购客户**（自然年下单 ≥ 3 次），分析其城市分布、品类偏好、价格带偏好
3. **量化城市退货率**，关联高复购客户密度，识别优质/问题城市
4. **分析品类销售与退货关系**，识别质量问题品类与高复购客户购买品类
5. **关联客户分层与退货行为**，评估不同价值客户的售后成本

## 🔍 分析框架

### 模块1：RFM 基础指标计算
**文件**：`sql/01_rfm_base.sql`  
**逻辑**：计算每位客户的 R（最近购买间隔）、F（总购买频次）、M（总消费金额），并标记高复购客户（自然年下单 ≥ 3 次）。  
**输出**：`customer_id`, `city`, `signup_date`, `R`, `F_all`, `M`, `is_high_rebuy`

### 模块2：RFM 客户分层
**文件**：`sql/02_rfm_segmentation.sql`  
**逻辑**：基于 RFM 五分位评分（NTILE 5 分档），将客户划分为 5 类：

| 客户类型 | 判定规则 | 运营策略建议 |
|----------|----------|--------------|
| **重要高价值客户** | R≥4, F≥4, M≥4 | VIP 专属服务、新品优先体验 |
| **高频低消费客户** | F≥4, M≤2 | 提升客单价、组合营销 |
| **沉睡高复购老客** | R≤2, F≥4 | 召回激活、限时优惠 |
| **低频零散客户** | F≤2 | 培养购买习惯、首单优惠 |
| **潜力待激活客户** | 其他 | 常规运营、持续触达 |

**输出**：`rfm_tag`（如 555）、`cust_type`（客户分层标签）

### 模块3：高复购客户城市月度分布
**文件**：`sql/03_high_rebuy_city_month.sql`  
**逻辑**：按城市和注册月份统计高复购客户的平均 RFM 指标。  
**价值**：识别高复购客户的地理分布和时间分布规律，指导城市运营和新客获取策略。

### 模块4：城市退货与高复购分析
**文件**：`sql/04_city_return_analysis.sql`  
**逻辑**：计算各城市的订单退货率，关联高复购客户数量。  
**价值**：发现"高复购但高退货"的问题城市，或"低退货但低复购"的潜力城市。

### 模块5：品类销售与退货分析
**文件**：`sql/05_category_sales_return.sql`  
**逻辑**：分析各品类的总销量、退货量、退货率，以及高复购客户的购买占比。  
**价值**：识别退货率高的品类（供应链/质量问题），以及高复购客户偏好的品类（重点备货）。

### 模块6：高复购客户价格带与供应商分析
**文件**：`sql/06_price_supplier_analysis.sql`  
**逻辑**：将商品按价格分为三档（低价 <50 / 中端 50~200 / 高价 >200），分析高复购客户的购买偏好及供应商分布。  
**价值**：指导采购策略和供应商管理，优化高复购客户的商品结构。

### 模块7：客户分层占比统计
**文件**：`sql/07_customer_type_ratio.sql`  
**逻辑**：统计各客户分层的客户数量及占比。  
**价值**：直观展示客户结构，评估运营健康度。

### 模块8：客户分层与退货行为关联
**文件**：`sql/08_customer_type_return.sql`  
**逻辑**：分析不同客户分层的平均退货次数。  
**价值**：评估不同价值客户的售后成本，优化服务资源配置。

## 🛠️ 技术栈

- **数据库**：MySQL 8.0+
- **SQL 特性**：CTE（WITH 子句）、窗口函数（NTILE）、条件聚合（IF/IFNULL）、临时表
- **数据来源**：Kaggle 零售数据集
- **分析工具**：Navicat Premium
- **数据导出**：Excel（用于可视化呈现）
